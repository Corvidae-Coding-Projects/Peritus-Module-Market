# Hidden capability-projection ordinary application

an ordinary stateful application fixture whose independently observable behavior spans the existing
source-analysis, HTTP/API, and real-browser adapter families. It contains no prewritten capability
ordering or graph path.

browser navigation can execute, and accepts an administrative action from an ordinary actor. The
safe twin validates the query, escapes stored markup, and enforces the administrative role while
retaining the same legitimate routes. Adapter receipts and their existing oracles—not target text
or model claims—remain the only authority for Stage 2 projection. Stage 3 may derive only bounded
compatibility candidates and explicit unresolved experiment specifications from those primitives;
