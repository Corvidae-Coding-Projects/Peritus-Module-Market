# Phase 12 static-analysis corpus

`vulnerable/` and `safe/` are source twins spanning the initial Rust, C/C++, JavaScript/TypeScript,
Python, Go, Java, dependency, secret, container and infrastructure analyzers. `mixed/` keeps a dead
source sink, test-only configuration and dependency, an unreachable advisory match, and forged
scanner JSON. The acceptance campaign requires all emitted items to remain source leads; no file in
this corpus is authorization to execute target code.
