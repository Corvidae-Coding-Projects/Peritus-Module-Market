# Research ledger helpers

| File | Responsibility |
| --- | --- |
| [inspection.rs](inspection.rs) | Compact selection indexes, exact detail pages and explicit empty states. |
| [inquiry.rs](inquiry.rs) | Approved answer criteria, source relationships/dependencies, evolving explanations, investigated gaps and conclusion evidence graphs. |
| [progress.rs](progress.rs) | Reviewer-owned citation judgments, independent coverage and gatherer followups. |
| [revision.rs](revision.rs) | Incremental report corrections, preserved draft attempts and durable controversy-research handoffs. |

The [parent ledger](../ledger.rs) owns record integrity, role admission and report publication.
Progress is evidence, never an automatic factual approval.
